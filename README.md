# 教练我错了 · 毒舌驾考陪练（可交互原型 v2）

把最枯燥的科目一/科目四死记硬背，改造成「社死驱动的学习」：
答错被教练方言毒舌开骂并连坐刷题，答对收获傲娇彩虹屁，挂科出《事故报告单》。

> 毒舌是壳，记忆效率是核。只骂错误操作，不攻击人格（禁词：笨 / 蠢 / 废 / 智商）。

## 在线体验

- 在线预览（任何浏览器直接打开）：https://htmlpreview.github.io/?https://github.com/yyyyyeying-lgtm/acc/blob/main/index.html
- 仓库地址：https://github.com/yyyyyeying-lgtm/acc

## 功能一览

| 模块 | 说明 |
|---|---|
| 首页 · 选教练 | 东北老张 / 川渝幺妹 / 教导主任三选一，点击试听口头禅，语音、语调随人设变化 |
| 刷题主循环 | 答对：绿色弹跳 + 30% 概率傲娇夸夸；答错：红色抖动 + 正确答案闪绿 + 方言毒舌（打字机 + 语音） |
| 连坐机制 | 答错可「接受连坐 · 3 题」，中途再错题数 +1（上限 5）；全过才放行 |
| 连对彩蛋 | 连对 5 题弹「教练心情好」，发免骂金牌 ×1，下一道错题自动抵扣 |
| 模拟考 | 10 题 / 5 分钟，教练全程沉默离场，倒计时红色呼吸；交卷后黄黑条纹「渡劫」扫场 2 秒 |
| 结算 | ≥90 出绿框《结案书》，<90 出黄底《事故报告单》：红章「挂科专用章」盖章动画 + 肇事知识点 Top3 + 教练判词 |
| 分享卡片 | 9:16 海报，↑↓ 换一条最狠骂语，canvas 手绘导出 PNG（离线可用） |
| 考前夜话 | 深蓝夜空 + 月亮，三段温柔文案慢速打字，金句收尾：「明天别慌。题没你狠，但它比你怕你。」 |
| 错题本 | 按知识点手风琴分组，含「回忆杀」骂语原文（带当时教练名）与复习要点，支持只刷错题的重修模式 |
| 设置 | 教练切换、语音开关、温柔模式（去感叹号 + 音量 -20%）、重置进度 |

## 技术说明

- 单文件 H5：`index.html`，原生 HTML/CSS/JS，零构建、零依赖、零 CDN，可直接静态托管
- 设计视口 390×844，桌面端居中手机壳展示，移动端全屏
- 语音：Web Speech API（`speechSynthesis`），预留真人方言音频替换口
- 数据：内置 10 题题库 × 3 教练全量话术（60 条骂/夸）+ 连坐话术池
- 进度持久化：`localStorage`
