# 「教练我错了」交互原型方案 v1.0
> 毒舌 AI 驾考陪练 · 科目一 / 科目四
> 本文档可直接投喂 AI 前端工具（v0 / bolt / Cursor 等）生成可交互原型。

---

## 0. 给原型生成 AI 的开工指令

- 形态：**移动端 H5 单页应用**，设计视口 390×844，居中显示。
- 技术栈：React + Tailwind（或单个 HTML 文件 + Tailwind CDN 皆可），**无后端**。
- 数据：直接内置第 7 节的 10 题题库与话术 JSON，所有语音文案全部来自该数据集。
- 语音：用浏览器 `SpeechSynthesis` 播放文案占位；预留 audio 接口可替换真人方言音频。
- 必须实现的页面（按此顺序做）：
  1. 首页·选教练
  2. 刷题页（主循环，含骂/夸/连坐）
  3. 模拟考页
  4. 结算页（事故报告单 / 结案书）
  5. 分享卡片
  6. 考前夜话
  7. 错题本
  8. 设置

---

## 1. 产品一句话

把最枯燥的科一科四死记硬背，改造成"社死驱动的学习"：答错被教练方言毒舌语音开骂并连坐刷题，答对收获傲娇彩虹屁，挂科出《事故报告单》。毒舌是壳，记忆效率是核。

## 2. 全局设计基调

- **配色**：驾校橙 `#FF7A00` 主色 + 黄黑警示斜纹条做分隔装饰 + 深灰 `#1F1F1F` 底色；大圆角卡片。
- **字体**：题干 20px 起步，话术气泡 17px，重点词用橙色加粗。
- **教练语音呈现**：聊天流形式（左侧教练气泡 / 右侧我方气泡），气泡文字**打字机逐字输出**，同时播放语音；气泡旁教练头像随说话节奏轻微晃动。
- **人设口径**：教练自称"我 / 老张 / 幺妹 / 王主任"，称呼用户"同学 / 小朋友 / 你小子"。
- **情绪原则（重要）**：只骂"错误操作"，不攻击人格。禁用词：笨、蠢、废、智商。句式偏好"这题错得离谱，但你人不差"。

## 3. 教练人设卡（首页选择用）

| 教练 | 名号 | 方言/风格 | 口头禅 | 骂人画风 | 夸人画风 |
|---|---|---|---|---|---|
| 张教练 | 「东北老张」 | 东北话 | "麻溜的！" | 大嗓门+离谱比喻 | 咋咋呼呼的实在嗑 |
| 幺妹教练 | 「川渝幺妹」 | 四川话 | "要得嘛！" | 辣中带娇、灵魂反问 | 软乎夸人夹规矩 |
| 王主任 | 「教导主任」 | 标准普通话 | "很好，我记下了。" | 阴阳怪气+格式化判词 | 冷面毒舌式肯定 |

## 4. 页面流与交互详述

### 4.1 首页·选教练
- **布局**：顶部产品名「教练我错了」+ slogan「科目一，先过教练这一关」；中部 3 张教练竖卡（头像、名号、口头禅、风格标签）；底部黄色按钮「开始挨骂」。
- **交互**：
  1. 点击教练卡 → 播放该教练 1 句试听语音，卡片抖动一下并选中态（橙色描边）。
  2. 点「开始挨骂」→ 进入刷题页。
  3. 右上角小入口：错题本、设置。

### 4.2 刷题页（核心主循环）
- **布局**：
  - 顶部：返回箭头 + 进度条（第 n/10 题）+ 正确率徽章 + 连对火焰计数 🔥×N。
  - 中部：教练头像悬浮在聊天流上方；题干卡片（大字）；选项列表（判断题 2 项 / 单选 4 项）。
  - 底部：主按钮「确认答案」。
- **状态机**（原型必须实现）：
  1. `idle` → 点选选项（橙色描边）→ 点确认。
  2. **答对**：选项变绿 + 轻微弹跳 → 30% 概率触发「夸夸语音气泡」（打字机+语音）→ 1.5s 后出「下一题」按钮；连对计数 +1。
  3. **答错**：所选选项变红 + 左右抖动 0.5s → 正确答案闪绿边 → 教练头像弹到聊天流，输出「毒舌话术」气泡（打字机+语音，不可跳过，但可点气泡跳过打字直接显示全文）→ 气泡下方出现两个按钮：「认怂下一题」（灰色）/「接受连坐 · 3 题」（橙色描边）→ 本题自动进错题本，连对计数清零。
  4. **连对彩蛋**：连对满 5 题 → 全屏短暂弹出「教练心情好」横幅，发放「免骂金牌 ×1」（下一道错题免骂，只显示温和版提示），并播一条傲娇夸语。
- **连坐模式**：
  - 进入后顶部出现橙色警示条「连坐挑战 0/3」，从题库中抽 3 题（原型阶段随机抽未做过的题即可，标注知识点归属）。
  - 3 题全对 → 教练"勉为其难"放行语音气泡："行，算你过关，下不为例！"
  - 中途再错 → 连坐未完成题数 +1（最多累计到 5），并再播骂语。

### 4.3 模拟考页
- **规则**：原型配置 **10 题 / 5 分钟**（正式版 100 题 / 45 分钟）；顶部倒计时（红色呼吸）+ 题号进度。
- **关键设定：考试中教练全程沉默**——没有语音、没有表情，界面明显变冷清（去掉头像）。营造"考场没有人救你"的压迫感。
- 交卷或倒计时归零 → 播放 2 秒"渡劫"过渡动画（黄黑警示条纹扫过）→ 进结算页。

### 4.4 结算页（事故报告单 / 结案书）
- **得分 ≥ 90** → 「结案书」：绿色边框文书样式，文案"结案陈词：准予上路……的感觉还早，先去科二挨骂。"+ 教练傲娇夸语一条。
- **得分 < 90** → 「事故报告单」：仿交警罚单排版（黄底黑字+红章"挂科专用章"），包含：
  - 得分大字 + "距离挂科只差 X 分"（<95 时）/ "事故等级：重大（灯光题连续肇事 N 起）"
  - **肇事知识点 Top3**（按错题知识点聚合）
  - 教练判词（按所选人设给一句总结骂，预置在数据集 `report_roast` 字段）
  - 底部按钮：「领取罚单 · 错题重修包」（跳错题本）/「生成分享卡片」。
- **交互细节**：报告单出现时做"啪"一声盖章动画，语音同步念得分。

### 4.5 分享卡片
- 竖版海报 9:16：顶部产品 logo + 中间大字成绩 + "今日被教练骂了 N 次" + 最狠一条骂语原文（引用样式）+ 教练印章 + 底部二维码占位。
- 「保存图片」用 html2canvas 之类截取；预览态可上下滑动更换骂语条目。

### 4.6 考前夜话（反差彩蛋）
- **入口**：结算页通过后出现「考前夜话」入口；首页也常驻小入口。
- **场景**：整个页面切深蓝夜空 + 月亮，教练头像换成柔和版，无警示条纹。
- **内容**：固定 3 段温柔文案逐条淡入（打字机，慢速），最后一条金句：
  "明天别慌。题没你狠，但它比你怕你。"
- 可随时「返回」，不打扰。

### 4.7 错题本
- 按知识点分组的手风琴列表；每题展开后显示：题干、当时答错记录、**当时的骂语原文（"回忆杀"标签）**、知识点复习要点一句。
- 顶部按钮「重修模式」：只刷错题，全清空时播放夸夸语音"清零了！老张这辈子没见过改这么彻底的。"

### 4.8 设置
- 教练切换、语音开关、「温柔模式」开关（开启后骂语替换为唠叨版：同一句骂语去掉感叹号，音量降 20%）、重置进度。

## 6. 话术兜底与 LLM 生成策略

- 原型与演示一律使用第 7 节**预置话术**（演示稳定性优先）。
- 正式版接 LLM 时，人设 system prompt 模板：

```
你是{人设名}，一位{方言}驾校教练，负责监督学员刷科目一题库。
规则：
1. 只嘲讽"错误操作/错误认知"，绝不攻击学员人格，禁用词：笨、蠢、废、智商。
2. 输出≤60字，口语化，必须包含一句该知识点的正确结论（把知识点藏进笑点里）。
3. 结尾给出行动指令（如"连刷三题"）。
4. 若学员答对：傲娇式夸奖，夸奖必须复述知识点，不许空夸。
```
